DSP Pipeline Summary ▾
1. Memory Management & LED Auto-Adjustment
  • Fixed-size circular buffers (100 samples, about 2s) hold recent red/IR readings. The oldest sample drops as each new one arrives, so memory use stays constant.
  • If the IR DC baseline is too weak, LED drive current steps up until signal strength clears a target threshold. This is what compensates for differences in skin tone, tissue depth, and finger placement.
  • A cooldown period locks out further adjustments until the new brightness has settled. Low or no-contact signal resets LEDs and clears buffers so bad data doesn't propagate.
2. Bandpass Filter (AC/DC Split)
  • DC baseline is the rolling average of the buffer, the large slow component from tissue and bone.
  • AC component is the DC baseline minus the latest sample, the small fast component from blood volume change.
  • AC is smoothed with a 4-sample moving average (a simple lowpass) to reduce jitter before beat detection.
3. SpO2 Calculation (Ratio-of-Ratios)
  • RMS amplitude of the AC component is computed separately for the red and IR channels.
  • A ratio R is formed from log(AC+DC) minus log(DC) for red, divided by the same for IR. This normalizes out absolute signal strength, working alongside the LED auto-gain in step 1 to keep readings consistent across different fingers.
  • R is passed through an empirical calibration curve (quadratic, fit to reference data) to output %SpO2, clamped to a plausible 70-100% range.
4. BPM Detection (Adaptive Threshold)
  • Beat threshold is recalculated every cycle as 30% of the current RMS IR amplitude, so it scales with signal strength instead of using a fixed cutoff.
  • A beat is registered when the smoothed AC signal rises above that threshold. The time since the last beat gives an instantaneous BPM.
  • Instant BPM is only accepted within a 300-1500ms window (40-200 BPM) and blended with the running value (80% old, 20% new) to reduce jitter.
